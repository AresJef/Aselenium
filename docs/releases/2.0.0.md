# Aselenium 2.0.0

Aselenium 2.0.0 is a major modernization of the asynchronous browser-automation
package. It introduces transactional driver management, strengthens browser and
session ownership, expands installed-wheel and native-browser acceptance, and
removes the legacy compatibility surface retained by the 1.x series.

## Highlights

- Added exact, compatible, cached, and offline driver-resolution policies where
  the browser vendor supports downloadable drivers. Safari retains stable/dev
  system-driver discovery without a downloadable-driver cache.
- Replaced the legacy cache with a concurrency-safe SQLite v2 index, immutable
  artifacts, integrity checks, atomic publication, persistent pins, and active
  acquisition leases.
- Hardened asynchronous command deadlines, cancellation, session transactions,
  process ownership, crash recovery, profile isolation, and cleanup retries.
- Action dispatch now detaches each pending batch before awaiting the browser,
  preventing overlapping calls from replaying input and preserving input queued
  during an earlier dispatch or reset, including after failure or cancellation.
- Transaction admission now honors the enclosing wait/command deadline or the
  configured session timeout. Chromium permission changes, Firefox context
  changes, and Safari permission updates keep their mutation and observation
  together so independent tasks cannot overwrite or misreport each other's state.
- Optional delays are validated before browser side effects. Inspecting session,
  element, shadow-root, and alert handles no longer allocates a service port.
- Expanded current W3C WebDriver support across elements, windows, frames,
  shadow DOM, alerts, cookies, JavaScript, action chains, screenshots, PDF
  output, browser-specific commands, and concurrent sessions.
- Added type information through `py.typed`, improved public annotations and
  docstrings, and added runnable local-HTML and Google demonstrations.
- Standardized filesystem handling on `pathlib.Path`: public APIs accept text
  or string-valued `os.PathLike` inputs, parse them once, retain `Path` values
  through internal workflows, and convert to text only at protocol, process,
  metadata, or compatibility boundaries. Chromium profile-folder basenames now
  reject traversal, cross-platform path syntax, and reserved Windows semantics
  before any profile is selected or copied.
- New-session creation now honors `options.session_timeout` instead of imposing an
  internal 10-second handshake ceiling, improving cold starts on slower hosts.
- Session teardown snapshots late browser descendants before the remote quit command
  can detach them from the driver process tree, and the service retries that snapshot
  before its own shutdown request when the first inspection fails.
- Hardened Windows cache coordination with a fixed byte-zero lock range,
  classified contention and release failures, and actionable child-process
  diagnostics for native CI failures.
- Added a typed Firefox `profile_root` service option for Snap, Flatpak, and
  other container filesystems. It accepts text/path-like input, validates once,
  retains `Path` internally, requires GeckoDriver 0.32.0 or newer, and rejects
  ambiguous duplicate raw flags.
- Configured release-gated regression coverage for Python 3.10 through 3.14,
  exact minimum runtime dependencies, installed distributions, and native Chrome,
  Firefox, Edge, and Safari operation on hosted runners.

## Verification and support boundaries

The pre-release local review passed 3,263 tests on Python 3.13.12/macOS ARM64,
with the Windows drive-relative syntax case skipped on that platform. Installed
wheel tours passed all 15 stages on Chrome, Edge, and Firefox, and all 12
applicable stages on Safari. The tagged release workflow separately gates
publication on its hosted Python/OS/native matrix and 600-second Chromium
reliability workloads.

Safari's current facade does not support frame switching, action chains,
concurrent acquisitions, custom proxies, or PDF printing. Browser-specific
commands and driver availability remain dependent on the installed vendor
version. A bounded acceptance workload is not an unlimited-uptime guarantee.

Google examples use the real website, but consent, CAPTCHA, and page changes can
prevent completion. The demo does not bypass these restrictions. Local HTML
fixtures provide the repeatable feature tour.

See the [pre-deployment review](https://github.com/AresJef/Aselenium/blob/v2.0.0/docs/pre-deployment-review.md)
for artifact identity, exact local results, both recovery attempts, and the
distinction between verified behavior and environment-specific limits.

## Breaking changes

- Removed legacy Feather-cache migration and the pandas/pyarrow dependency path.
- Removed JSON Wire compatibility responses, obsolete protocol routes, old DOM
  helper atoms, and deprecated aliases.
- Removed `Element.visible`, `Element.viewable`, and hybrid
  `Element.get_attribute()` behavior. Use the explicit viewport, hit-test, DOM
  attribute, and property APIs documented in the migration guide.
- Removed the monolithic demo and bundled legacy test assets. Use
  `src/demo_local.py` or `src/demo_google.py`.
- Chrome and Chromium driver management now targets browser version 115 and newer.
- Firefox add-ons must use WebExtension manifests.
- Proxy construction and several validation paths are intentionally stricter.

See the [breaking-change guide](https://github.com/AresJef/Aselenium/blob/v2.0.0/docs/legacy-removal.md)
for replacements and the [README](https://github.com/AresJef/Aselenium/blob/v2.0.0/README.md)
for installation, driver-management policies, complete usage examples,
troubleshooting, and browser-specific support boundaries.

## Requirements

- Python 3.10 or newer.
- `aiohttp>=3.14.3`
- `psutil>=5.8.0`
- `orjson>=3.11.6`
- An installed supported browser, except when using a provisioned Chrome for
  Testing browser/driver pair.

Install the wheel attached to this GitHub Release with:

```bash
python -m pip install --upgrade https://github.com/AresJef/Aselenium/releases/download/v2.0.0/aselenium-2.0.0-py3-none-any.whl
```

If the optional PyPI promotion was enabled for the release, the equivalent
index installation is:

```bash
python -m pip install --upgrade aselenium==2.0.0
```
