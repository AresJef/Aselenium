# Aselenium 2.0.0

Aselenium 2.0.0 is a major modernization of the asynchronous browser-automation
package. It introduces transactional driver management, strengthens browser and
session ownership, expands installed-wheel and native-browser acceptance, and
removes the legacy compatibility surface retained by the 1.x series.

## Highlights

- Added exact, compatible, cached, and offline driver-resolution policies where
  the browser vendor supports downloadable drivers. Safari retains stable/dev
  system-driver discovery without a downloadable-driver cache.
- Replaced the legacy cache with a concurrency-safe SQLite v2 index, immutable
  artifacts, integrity checks, atomic publication, persistent pins, and active
  acquisition leases.
- Hardened asynchronous command deadlines, cancellation, session transactions,
  process ownership, crash recovery, profile isolation, and cleanup retries.
- Expanded current W3C WebDriver support across elements, windows, frames,
  shadow DOM, alerts, cookies, JavaScript, action chains, screenshots, PDF
  output, browser-specific commands, and concurrent sessions.
- Added type information through `py.typed`, improved public annotations and
  docstrings, and added runnable local-HTML and Google demonstrations.
- Added regression coverage for Python 3.10 through 3.14, exact minimum runtime
  dependencies, installed distributions, and native Chrome, Firefox, Edge, and
  Safari operation on hosted runners.

## Breaking changes

- Removed legacy Feather-cache migration and the pandas/pyarrow dependency path.
- Removed JSON Wire compatibility responses, obsolete protocol routes, old DOM
  helper atoms, and deprecated aliases.
- Removed `Element.visible`, `Element.viewable`, and hybrid
  `Element.get_attribute()` behavior. Use the explicit viewport, hit-test, DOM
  attribute, and property APIs documented in the migration guide.
- Removed the monolithic demo and bundled legacy test assets. Use
  `src/demo_local.py` or `src/demo_google.py`.
- Chrome and Chromium driver management now targets browser version 115 and newer.
- Firefox add-ons must use WebExtension manifests.
- Proxy construction and several validation paths are intentionally stricter.

See the [breaking-change guide](https://github.com/AresJef/Aselenium/blob/v2.0.0/docs/legacy-removal.md)
for replacements and the [README](https://github.com/AresJef/Aselenium/blob/v2.0.0/README.md)
for installation, driver-management policies, complete usage examples,
troubleshooting, and browser-specific support boundaries.

## Requirements

- Python 3.10 or newer.
- `aiohttp>=3.14.3`
- `psutil>=5.8.0`
- `orjson>=3.11.6`
- An installed supported browser, except when using a provisioned Chrome for
  Testing browser/driver pair.

Install the wheel attached to this GitHub Release with:

```bash
python -m pip install --upgrade https://github.com/AresJef/Aselenium/releases/download/v2.0.0/aselenium-2.0.0-py3-none-any.whl
```

If the optional PyPI promotion was enabled for the release, the equivalent
index installation is:

```bash
python -m pip install --upgrade aselenium==2.0.0
```
